# SpaceInvadersGame
This project is a Space Invaders Game developed in Java using Swing for the graphical user interface. Here’s a brief breakdown of the key components:
	
•	App.java: This is the main entry point of the program. It sets up a full-screen JFrame window and initializes the game by adding an instance of the SpaceInvaders game panel.

•	SpaceInvaders.java: This is the core of the game logic and rendering. It handles the game’s graphics, player controls, alien movement, and game interactions. It listens for keyboard input to move the player ship and shoot projectiles, updating the game state in real-time.

•	PauseMenu.java: This class represents the pause menu displayed during the game. It provides options for the player to resume, restart, or exit the game. It uses a listener-based design to handle button clicks and communicate back to the main game logic.

The game supports:

•	Full-screen mode for immersive gameplay.

•	Keyboard controls for player interaction.

•	Pause functionality with a simple interface for managing game state.

This is a fun project to explore Swing’s potential and implement classic game mechanics in Java. ￼
